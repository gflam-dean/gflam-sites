## How the hashes were computed

```python
import hashlib, io, re
def read(p): return io.open(p, encoding='utf-8', newline='').read().split('\n')
def block(lines, start_re, end_re):
    for i, l in enumerate(lines):
        if re.match(start_re, l):
            for j in range(i, len(lines)):
                if j > i and re.match(end_re, lines[j]):
                    return i + 1, j + 1, hashlib.sha256(('\n'.join(lines[i:j+1]) + '\n').encode()).hexdigest()
def one(lines, n): return hashlib.sha256((lines[n-1] + '\n').encode()).hexdigest()
# e.g. block(read('venueplay-backend/worker/vp-draw.js'), r'^function randInt\(', r'^}')
#      one(read('venueplay/app/vp-draw.js'), 28)
```

A multi-line piece runs from the line matching its opening pattern (the function's first line, or the `VP-STRIP BEGIN` marker) to the first later line that is exactly its closing brace at the same indentation (or the `VP-STRIP END` marker). A single-line piece is that line alone.
