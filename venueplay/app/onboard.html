Onboard a venue
Creates the venue, its default settings and one TV screen. The venue slug becomes the TV web address screen.venueplay.com.au/<slug>.
Venue
Lowercase, hyphens, no spaces. Must be unique. Auto-filled from the name, edit if needed.
Billing parent (exactly one)
Grouped operator
Independent (card)
A venue must attach to exactly one billing parent. Grouped venues are invoiced through an operator group. Independent venues are card-billed through their founding subscription record.
Groups are set up in the admin. If a group is missing, add it first.
The independent venue's paid subscription record. It is created when they sign up on the founding page (Worker, service role), so the browser cannot create it here. Copy its id from the Supabase Table Editor (venueplay_founding). The player cap is read from that record's max_seats.
First manager (optional)
A manager needs a Supabase Auth user, which can only be created with admin/service-role access (Authentication → Users in Supabase, or a future service-role endpoint). Create the user there, tick Auto Confirm, then paste their User UID here to link them as this venue's manager. You can also skip this and add staff later.
