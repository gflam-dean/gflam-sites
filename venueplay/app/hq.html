Venues that have gone quiet
VenueQuiet forLast gameState
Sorted shortest quiet first, because a venue that missed one week is the one you can still win back. Last game counts every format: sessions for trivia, musical bingo and raffles, and game reports for broadcast bingo, which opens no session. Bingo is recorded from the first ball, so a night the host never formally ended still counts. A venue that has never run a night is measured from the day it was set up. We only look back a year, so an older venue with nothing in that window reads over a year rather than never.
