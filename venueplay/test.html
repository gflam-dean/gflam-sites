Help us break VenuePlay

VenuePlay turns the TV in a pub or club into a live game night. The venue runs bingo, trivia, musical bingo, a raffle draw or a members draw straight off the big screen, and the room joins in on their phones. No app to download and no account to make.

This is a pre-launch test build, not the finished product. You have it for a week. Please try hard to break it, and jot down anything that is confusing, slow, ugly or plain broken. Rough edges are exactly what we want to hear about.

What you will need

A laptop or tablet for the Screen (this stands in for the venue TV), the same or a second device for the Host console, and your phone to join as a player. Two browser tabs on one laptop plus your phone is plenty.

The one rule that makes it all connect

Every game is built around a 6-character room code. Always open the Screen first: it shows the code. Type that code into the box on the card below, then open the Host and Player links and they will all land in the same room. Codes use letters and numbers only, no lookalikes like O or I.

Screen / TV
The big screen in the room. Shows the code, the QR and the game.
Host
The staff console. Runs the game and calls the numbers or questions.
Player
A punter on their phone. Joins with the code and plays along.
The five formats

Bingo 3 roles

Classic 90-ball bingo. The host calls the numbers, phones mark their cards, first to the pattern hits BINGO.

  1. Open the Screen
    On your laptop or TV browser. It shows a pairing code in the corner. This is your room code.
    Open the Screen ↗
  2. Type the code from the screen
    Read the 6 characters off the screen and pop them in here. It wires up the two buttons below.

  3. Open the Host console
    On the Host tap Skip for demo, the code will already be filled in, then tap Connect. Pick a prize, tap Start game, then Next number to call balls.

  4. Join as a Player
    On your phone. Enter your name and wait for the host to start. Or just scan the QR on the screen.

Musical Bingo 3 roles sound on

Bingo, but with songs instead of numbers. Cards are full of song titles. The host plays a clip, players mark the track they hear.

Run the Host with the sound up

The Host device now plays a real preview clip of each song, about 30 seconds, through whatever it is plugged into. Turn the volume up, or plug the Host into a speaker, so players can actually hear the track. Everything else works fine on a phone or laptop.

  1. Open the Screen
    Shows the code and the QR. Keep it visible in the room.
    Open the Screen ↗
  2. Type the code from the screen
    6 characters, off the screen, into here.
    Waiting for a 6-character code...
  3. Open the Host console (sound up)
    The code is filled in, tap Connect. Tap Start game, then Play next song to play a clip out loud and reveal the title.
    Open Host ↗
  4. Join as a Player
    On your phone, enter your name, then mark the song you hear. Or scan the QR on the screen.
